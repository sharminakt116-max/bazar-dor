Project name: বাজার দর / BazarDor

Description: BazarDor is a web application that helps users explore the prices of essential daily products in Bangladesh. Users can browse products by category, view product details, and sort products by price to find the information they need easily.

Technologies used

1.Next.js
2.TypeScript
3.Tailwind CSS
4.REST API
5.Better Auth
6.MongoDB
7.React.js
 
Key Features
1. Product Categories: Browse essential products such as rice, lentils, oil, vegetables, fish, and meat by category.
2. Product Details: View product information, current prices, and available market price details.
3. Price Sorting: Sort products by price from low to high or high to low.
4. User Authentication: Sign up and sign in securely to access user account features.
5. Profile Management: View profile information and update personal details.
